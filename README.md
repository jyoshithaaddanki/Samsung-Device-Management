# 📱 Cloud-Based Samsung Device Management System

A simple web-based Samsung Device Management System developed using **HTML, CSS, and JavaScript**.

## 🚀 Features

- ➕ Add Samsung devices
- 🔍 Search devices
- 📋 View device details
- 🗑️ Delete devices
- 📱 Store device name, model, owner, and status
- 💻 Simple and user-friendly interface
- 🌐 Can be hosted using GitHub Pages

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
